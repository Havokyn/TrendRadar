# ChinaNewsStream - Keyword Monitoring Configuration
# English Example with Syntax Guide
#
# === SYNTAX GUIDE ===
#
# 1. Normal keywords (no prefix):
#    - Match any keyword in the group
#    - Example: Tesla, SpaceX
#
# 2. Required keywords (+prefix):
#    - Must appear together with normal keywords
#    - Example: +launch (requires "launch" in title)
#
# 3. Filter keywords (!prefix):
#    - Exclude news containing these words
#    - Example: !rumor (exclude news with "rumor")
#
# 4. Groups (separated by blank lines):
#    - Each group is independent
#    - Different groups track different topics
#
# === MATCHING LOGIC ===
#
# Group example:
#   Tesla
#   SpaceX
#   +Elon Musk
#   !rumor
#
# Matches:
#   ✅ "SpaceX launches satellite with Elon Musk" (has SpaceX + Elon Musk)
#   ✅ "Tesla announces new product with Elon Musk" (has Tesla + Elon Musk)
#
# Does NOT match:
#   ❌ "Tesla stock price rises" (has Tesla but missing "Elon Musk")
#   ❌ "Rumor: SpaceX and Elon Musk news" (has keywords but includes "rumor")
#
# === CONFIGURATION TIPS ===
#
# 1. Start broad, then narrow:
#    - First: Add general keywords
#    - Then: Add +required words to reduce noise
#    - Finally: Add !filter words to exclude spam
#
# 2. Keep groups focused:
#    - Don't mix unrelated topics in one group
#    - Create separate groups for different interests
#
# 3. Keyword priority:
#    - Keywords listed first have higher priority
#    - Arrange by importance to you
#
